# 1.0.0 — 2026-11-16

Первая версия программы ToadTools: она живёт в трее, сама ставит плагин [ToadTools](https://github.com/Alexpivo394/ToadTools) и обновляет его, когда Revit закрыт.

**Программа**
- Проверяет новую версию плагина на GitHub с выбранной частотой (по умолчанию раз в 6 часов), скачивает её и ставит, как только закрыт последний Revit, — без прав администратора и перезагрузки
- Уведомления Windows: «Доступна версия…, закройте Revit — обновлю сам» и «ToadTools обновлён»
- Окно настроек: частота проверки, автоматическое скачивание и установка, версии Revit, запуск вместе с Windows, уведомления, прокси, «Что нового» и папка логов
- Скачанные файлы проверяются цифровой подписью: подменённый или повреждённый файл не ставится
- Обновляет и саму себя: новая версия программы ставится тихо, в фоне

**Установщик**
- Ставит программу для текущего пользователя, права администратора не нужны
- Удаляет плагин, поставленный старым установщиком ToadTools 4.0.x; плагин программа скачает сама
- Удаление программы убирает и плагин из всех версий Revit
